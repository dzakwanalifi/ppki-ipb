# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-15

### Added
- **PPKI Knowledge Base**: Digitalized and structured Markdown version of the official IPB University PPKI 2024.
- **Gemini CLI Skill**: Packaged `.skill` file for procedural writing standards.
- **Claude Code Integration**: Added `CLAUDE.md` for terminal-based AI context.
- **Cursor & Windsurf Rules**: Added `.cursor/rules/` for automated IDE formatting.
- **Universal Agent Standard**: Added `AGENTS.md` for cross-platform compatibility.
- **GitHub Copilot Instructions**: Added `.github/copilot-instructions.md`.
- **Search Tool**: Python utility for querying the knowledge base.

### Changed
- Refactored repository structure to follow "AI-Native" best practices.
- Organized data into `raw` and `structured` directories.
- Moved automation scripts to `scripts/`.
